# LaunchPal tracker

The privacy-friendly analytics script behind [LaunchPal](https://launchpal.app): visitors, where they
came from and what they did, without cookies or personal data.

- No cookies, local storage or other data on the visitor's device
- No IP addresses or identities stored: visitors are counted with a code that changes every day
- Page views, sources, country, device, time on page, scroll depth and a few named goals
- Small, with no dependencies

The code moves here from the LaunchPal app once founders can add it to their own sites. Until then
this repository is a placeholder.
